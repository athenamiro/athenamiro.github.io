5 Cache Pricing Comparison 90%+ Discounts

Prompt caching is the single largest cost lever. Most providers give 90% off input for repeated prefixes. DeepSeek's 0.02× multiplier is the most aggressive.

Provider Cache Discount Cache Write Cost Min Cache Life Notes
DeepSeek V4 Flash 98% ($0.0028/M) Same as base input Automatic 0.02× multiplier — best in industry. Applied automatically.
OpenAI GPT-5.6 90% 1.25× base input 30 min Explicit cache breakpoints. Cache writes 1.25×.
Anthropic Claude 90% 1.25× (5 min) / 2× (1 hr) 5 min / 1 hr Two cache tiers. Cache reads don't count toward rate limits.
Google Gemini 90% Base input + storage fee Configurable Has hourly storage fee ($1/MTok/hr on Flash). Can cost more than no cache if rarely hit.
MiniMax M3 80% ($0.06/M) Same as base input Automatic Simple — no write surcharge, no storage fee.
Z.AI (GLM-5.2) 81% ($0.26/M) Same as base input Automatic Free storage (limited-time). Straightforward.
Stacking strategy: For agentic loops with repeated system prompts, cache hits can reduce effective input cost by 90%+. DeepSeek V4 Flash at $0.0028/M cached input is the absolute floor — ~$0.0007 per 250-token agent prompt.
